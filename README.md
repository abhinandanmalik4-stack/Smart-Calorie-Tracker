# 🍽️ Smart Calorie Tracker

A Python-based smart calorie tracking application that helps users monitor their daily calorie intake using food nutrition data and smart calorie analysis concepts.

The system allows users to select meals, specify quantity and serving size, and instantly calculate the total calories consumed throughout the day.

---

# 🚀 Features

- 📊 Daily calorie intake calculation
- 🍛 Multiple food item selection
- 🔢 Quantity and serving size tracking
- ⚡ Real-time calorie summary
- 📈 Smart nutrition and calorie analysis
- 🖥️ Interactive graphical user interface (GUI)

---

# 🛠️ Technologies Used

- Python
- Tkinter
- Pandas
- CSV Dataset Handling
- GUI Development

---

The project uses a processed Indian food nutrition dataset containing:
